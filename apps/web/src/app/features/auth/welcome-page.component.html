La idea que nos mueve

Las fotografías muestran cómo se veía. Las voces cuentan cómo se vivió.

Con el tiempo, una imagen puede quedarse sin contexto: quién estaba ahí, qué ocurrió antes o qué sintió cada persona. Memoria Viva nace para guardar esas historias junto a la fotografía, con espacio para más de una voz.

Queremos que recordar sea sencillo: abrir una colección, elegir un momento y volver a escuchar a quienes lo vivieron.

Ayuda rápida

Preguntas frecuentes

Soluciones para los problemas más comunes al empezar.

No puedo subir una fotografía, ¿qué reviso?

Usa JPEG, PNG, WebP o GIF de hasta 25 MB. Si el archivo cumple esos límites, prueba otra vez con una conexión estable y confirma que la API esté activa.

No puedo iniciar sesión

Confirma que el correo esté escrito correctamente y usa la contraseña registrada. Si aún no tienes cuenta, créala desde esta página. En desarrollo local, revisa también que la API y PostgreSQL estén funcionando.

¿Puedo escuchar mis recuerdos sin internet?

Sí. Abre la colección cuando tengas conexión y elige “Guardar para leer sin conexión”. Esa copia queda en el dispositivo donde la guardaste.

¿Mis colecciones son públicas?

No. En esta versión, cada cuenta accede únicamente a sus propias colecciones, recuerdos y personas.

No se graba mi voz

Permite el acceso al micrófono en el navegador. La grabación requiere HTTPS o localhost; también puedes cargar un archivo MP3, M4A, WAV, OGG o WebM de hasta 100 MB.
